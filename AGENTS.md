# EducationUnite project workflow

- Har nayi chat mein project ka kaam shuru karne se pehle `docs/PROJECT-STATUS.md` parho. Us mein scope, approvals, progress, blockers aur agla step milenge.
- Har part ke liye implementation se pehle Roman Urdu mein us part ka specific plan user ko dikhao. Plan mein scope, dependencies, expected changes aur verification likho. Usi part ki clear approval milne par implementation shuru karo. Roadmap review ko implementation approval mat samjho. Agar approved scope materially badle to updated plan ki approval lo.
- Har meaningful progress update ke saath `docs/PROJECT-STATUS.md` bhi update karo. Approval, kaam, checks, blockers aur agla step isi file mein record karo. Chat khatam karne se pehle verify karo ke file current hai. Passwords, tokens aur student data is file mein mat likho.
